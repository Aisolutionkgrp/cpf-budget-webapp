# CPF Philippines — AI Program Budget Control

เว็บแอปจริง (Next.js + Supabase) สำหรับติดตามต้นทุน/กำไร/ขาดทุนของ 35 โครงการ AI งาน CPF ฟิลิปปินส์

**3 สิทธิ์:**
- **PM** — กรอกทริปใหม่ได้อย่างเดียว (วันที่ / วิศวกร / โครงการที่ทำ / วันที่ทำ)
- **Admin** — แก้ไข/ลบได้ทุกอย่าง (เรตต้นทุน, มูลค่าโครงการ, logistic, hardware, ทริปทั้งหมด)
- **Executive** — ดู Dashboard อย่างเดียว (สิทธิ์ default ของผู้ใช้ใหม่ทุกคน)

**สูตรคำนวณต้นทุน** (ดูรายละเอียดใน `lib/costEngine.js`):
- ค่าแมนเดย์ = (เงินเดือน ÷ วันทำงาน/เดือน) × วันที่ทำจริง × จำนวนคน
- เบี้ยเลี้ยง/ค่าตั๋ว = คำนวณระดับทริป แล้วหารเฉลี่ยเท่ากันตามจำนวนโครงการในทริปนั้น
- Logistic = รวมทุกรายการ หารเฉลี่ยเท่ากันทั้ง 35 โครงการ
- Hardware = ผูกกับโครงการโดยตรง (ราคา × จำนวน)
- กำไร/ขาดทุน = มูลค่าโครงการ − ต้นทุนรวมทั้งหมด
